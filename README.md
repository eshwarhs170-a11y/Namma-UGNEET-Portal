# NammaUGNEET 🎯🩺

Your ultimate, data-driven smart predictor for NEET UG counseling. 

Navigating through KEA (Karnataka) and AIQ (All India Quota) cutoff PDFs is chaotic and frustrating. **NammaUGNEET** transforms thousands of fragmented data points into a lightning-fast, interactive search dashboard. Instantly discover your predicted MBBS, BDS, or AYUSH matches based on your rank, reservation category, and budget.

## ✨ Why NammaUGNEET?
- **Unified Portal:** Toggle seamlessly between State Quota (KEA) and All India Quota (AIQ).
- **Smart Predictor Matrix:** Highly accurate rank predictions that automatically map complex parameters (like high-fee management seats vs standard govt seats).
- **Crystal Clear Data:** We clean, parse, and organize raw counseling PDFs into a fast, crash-proof MongoDB database so you don't have to.

## 🚀 Quick Start

```bash
git clone https://github.com/eshwarhs170-a11y/Namma-UGNEET-Portal.git
cd namma-ugneet
npm install

# Setup your MongoDB connection
echo 'MONGODB_URI="your_mongo_url"' > .env.local

# Run the app locally!
npm run dev
```

*Built with React, Vite, Vercel Serverless Functions, and MongoDB.*
